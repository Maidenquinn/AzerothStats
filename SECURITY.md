# Security reporting

The maintainer reports permission to post Azeroth Stats as a verified addon on 28 October 2026. This is not independent security certification. See docs/APPROVAL-STATUS.md for scope.

Report public reliability issues at https://github.com/Maidenquinn/AzerothStats/issues with addon/client version, reproduction, expected behavior and sanitized diagnostics. Do not attach personal saves or private co-op/death histories.

For a potentially exploitable issue, use GitHub private vulnerability reporting **if enabled**, otherwise contact the maintainer privately through an established channel before publishing exploit details. No unverified address or response-time guarantee is provided here.

Scope: TOC-loaded runtime and packaged assets. Native client, launcher, other addons and downloaded saves are separate trust boundaries. See `docs/SECURITY-REVIEW.md`. API/persistence/validation/package changes require focused review and relevant regression checks.

# v2.0.4 SavedVariables size measurement protocol

## What can and cannot be measured in game

The addon can count retained runs and backup snapshots, but the game exposes no supported API for the byte length of the SavedVariables files. The new `/azstats storage` command intentionally reports counts only; it must not serialize or deep-copy the database just to estimate size.

Aviiva's report (about 100 MB at 144 runs) is a user-observed file size and load-time symptom. It is not yet a controlled before/after sample. The owner's approximately 84 MB at ~300 runs is not directly comparable because the number and contents of manual/automatic snapshots, optional details and backup rotations may differ.

## Required evidence before a storage-format change

Collect from a consenting test profile, after exiting the client normally:
- Exact file sizes for `AzerothStats.lua`, `AzerothStatsBackup.lua`, and `AzerothStatsAutoBackup.lua` (where present).
- Run count and backup snapshot counts from `/azstats storage`.
- File size before and after one manual backup and one automatic backup.
- File size before and after a controlled batch of 10 completed runs.
- Whether backups contain full run copies and how many run copies each holds.
- Load time measured with the same client, same hardware, same addon set, and repeated cold/warm starts.

Redact character/partner names, item links and any identifying text before sharing.

## Candidate optimizations (not yet implemented)

1. Avoid unnecessary full snapshots: keep existing exact-equality deduplication for automatic backups and verify backup cadence/retention settings.
2. Compact optional verbose per-run journals only behind a new versioned representation and reversible decoder. Do not change the current SavedVariables schema until round-trip and restore tests prove byte-for-byte semantic preservation.
3. Consider a shared string dictionary or compact positional arrays only after a fixture-based size report demonstrates material savings and WoW Logs confirms direct-reader compatibility.
4. Do not use RGB quantization, shorten user-visible names, or drop timeline/equipment/death evidence as a silent optimization.

No compression or migration is included in the current branch yet. The next practical step for a real measurement is the owner providing the three SavedVariables file sizes (or a redacted copy of the files) after a normal client exit.

# Azeroth Stats 2.0.5-alpha.1 — read-only storage inventory recipe

This is a **limited, non-destructive diagnostic alpha**, **not** a shared-backup migration test or release. The installed ZIP includes only the read-only `SharedStorageAudit.lua` feature; the migration model remains under `AzerothStats/tests/` and is **not loaded in-game**.

## Before installing
1. Fully close Azeroth Survivors.
2. Make a verified copy of all actual Azeroth Stats SavedVariables file(s); the three logical roots can share one physical `benilla-config/saved/AzerothStats.lua`. Use `tools/backup_savedvariables_safety.ps1` from this Git branch, and keep the independent backup separate.
3. Preserve the v2.0.4 ZIP so you can restore the previous version. Use a disposable copy of the game profile if possible.
4. Download the `AzerothStats-2.0.5-alpha.1.zip` artifact from the **latest green PR #39 GitHub Actions** run. Extract its single `AzerothStats` folder into the game's AddOns folder, replacing the existing one **without installing a second copy**. The review ZIP is not a stable GitHub Release.

## Native read-only test
1. Launch, verify the addon loads and existing Overview/My Runs/Favorites/Settings pages remain intact.
2. Run `/azstats storage` and write down the manual/auto backup counts (no raw SavedVariables shared).
3. Run `/azstats shared audit`. Expect active run count, manual/automatic checkpoint counts, stored run copies, distinct run IDs, repeated IDs. The latter are **candidates only**, not proven duplicate contents. No file size claim is made.
4. Exit the game fully and compare SavedVariables size and SHA-256 with the **before-test independent copy**. Other legitimate game activity/normal saving may change the file, so differences alone do not prove the audit caused a write; use a fresh isolated profile and avoid running any activities for a controlled test.
5. Test a `/reload`, then run the two commands again. Review the FR/EN command output; the diagnostic currently prints English debug text.
6. If a backup catalogue reports `audit incomplete`, stop and capture only its error message, not the raw data. Do not attempt to manually repair a large save.

**No new shared storage root exists in alpha. No migration, backup deletion, restore, snapshot creation or compression is performed by the new command.**

## Safe rollback
Fully exit the client. Replace the alpha addon folder with v2.0.4, and (if necessary) restore every original SavedVariables file from the independently verified copy. Relaunch and compare the inventory. Keep the safety copy after rollback.

## Not yet available
True on-disk backup sharing; durable staged migration across restarts; old-format cleanup; real 90–100 MB conversion timing; WoW Logs AS cross-version validation; native-client corruption and crash recovery. These remain hard release blockers and must never be inferred from the synthetic offline tests.

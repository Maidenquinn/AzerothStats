# Azeroth Stats — HUD hotfix · 1.7.1-beta.1

Thanks to ZA5TEESH for reporting the confusing **Bosses slain → Current run** display! ❤️

**What changed**
- Summary-only current-run counters now say **At run end**, with a tooltip explaining why.
- Once the official final summary arrives, the just-finished tracked run keeps its values until it is detached.
- Matching navigation and translations in all 14 languages.

This clarifies availability; it **doesn't add an exact live boss-kill counter**.
Your existing history and settings are preserved. No reset needed.

⬇️ **Download the player ZIP**
https://github.com/Maidenquinn/AzerothStats/releases/download/v1.7.1-beta.1/AzerothStats-1.7.1-beta.1.zip

Close the game, replace the addon folder, keep your SavedVariables, then fully restart.
Use `/azstats hud` to customize the bar. This hotfix still needs in-game feedback.

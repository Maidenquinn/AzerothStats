# Azeroth Stats v2.0.4 — performance and safety audit (2026-11-12)

Scope: source review of current PR #36, including `Core.lua`, `UI.lua`, `Tracker.lua`, `Theme.lua`, and the synthetic backup/storage benchmarks. This is **not** an in-game profiler capture.

## Runtime costs and existing safeguards

| Area | Observed behavior | Risk / recommendation |
| --- | --- | --- |
| Main driver | `Core.lua` has a per-frame OnUpdate timer, but returns until an accumulated 1-second interval. | Low ongoing callback overhead; do not describe this as a 60-Hz full scan. Profile the 1-Hz `A.Sample()` under combat and with large databases. |
| Run sampling | `A.Sample()` reads progress/identity and handles boundary, summary, lifecycle and accounting paths. | Keep native packet identity and interruption semantics; do not change sampling cadence without a native continuity regression. |
| Visible UI | `A.RefreshUI()` is capped at approximately every 3 seconds while visible; bar refresh is decoupled. | Avoid full-page rebuild every frame; test UI refresh cost in Overview, Analyze Run, large history and comparison pages. |
| Window closed | The driver still samples and refreshes smaller HUD/report elements; page rebuilding is skipped. | Confirm with a frame-time capture rather than assuming the closed window is cost-free. |
| Viewport/locale | Full `A.ApplyUI()` runs on viewport changes; auto language detection is gated at 30 seconds. | Theme/layout repaint can be expensive for many widgets; cache repeated unchanged dimensions and inspect resize-only behavior. |
| Material system | `Theme.lua` reuses registered nine-slice textures and short-circuits unchanged material/layout states. | Good existing allocation control; verify that the round minimap skin survives external minimap restyles without per-frame repaint. |
| Minimap button | A separate OnUpdate callback exists solely for drag; it returns immediately when not dragging. | Candidate for event-scoped registration only after tests establish no movement regression. Not changed in this audit. |
| Backups | `tools/benchmark_backups.py` exercises 100/500/1000 synthetic runs with Lua 5.1 mock; retention is asserted. | Results are synthetic timings, not game startup or FPS metrics. Full snapshots can amplify disk use; inspect real three-root files separately. |
| Storage proxy | `tools/benchmark_storage_candidates.py` models snapshots and zlib reduction using JSON, not WoW SavedVariables. | Report theoretical compression as a bound only; do not deploy zlib or migration based on this proxy. |

## High-priority measurement matrix

1. With the same machine and game settings: capture idle / solo combat / co-op combat frame time with the addon disabled, enabled with window closed, enabled with Overview open, and enabled with Analyze Run open.
2. Repeat at 10, 100 and 500 retained runs using anonymized fixtures, then with optional Combat Intelligence, Effects and Summons individually on/off.
3. Separate game FPS and CPU frame time from ordinary client startup, database load, automatic backup creation, UI refresh, and voluntary manual export.
4. Record exact disk bytes separately for `AzerothStats.lua`, `AzerothStatsBackup.lua` and `AzerothStatsAutoBackup.lua`; note retained run count and snapshot retention.
5. Test native vs FieldKit minimap skin for round/square, five addon themes, reload and repeated toggles, including screenshots at different UI scales.

## Safety and release boundaries

- No loss, truncation or implicit deduplication of recorded runs is acceptable.
- Do not drop unknown extension fields or rewrite historical data during experiments.
- Keep AZST1 export and WoW Logs direct SavedVariables reader compatibility intact.
- `interrupted` is **not** interchangeable with an officially observed `left` result.
- Co-op equipment/talent capture requires a proven native API; no speculative peer data.
- Native visual and performance verification remains **PENDING**. Offline CI is necessary but not sufficient.
- No merge, release tag or published package without owner acceptance.

## Findings for this patch

The circular icon previously combined a 30px tracking-border texture with a 17px central glyph inside a 30px button. The first review patch uses a 26px border and 20px glyph; it leaves the 30px click target, saved angle and parent frame unchanged. This is a visual hypothesis motivated by owner screenshots, not a confirmed native render fix.

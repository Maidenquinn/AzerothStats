⚔️ AZEROTH STATS — V2 PREVIEW 2.0.0-dev.11
Your runs. Your history. A clearer next step.

This is the first public V2 preview. It keeps your existing local history and settings, and adds the Chroniques-style experience teased earlier. Still a development candidate — not called stable.

🧭 SIX CLEAR ROUTES
Overview, My runs, Analyze, Progression, Favorites and Nemesis — with Settings and Diagnostics still one click away. V1 details remain reachable inside these paths.

🏠 OVERVIEW THAT ORIENTS YOU
See your current or preparation context, recent runs, measured takeaways and the next personal goal — without inventing a ready-state run.

📊 MEASURED CURVES & RICH REPORTS
Inspect observed progression plots, build changes, attributes with equipment contributions, and a movable illustrated run chooser with local search.

🎯 CUSTOM GOALS & LOCAL NOTES
Set personal targets (wins, kills, gold, damage, playtime and more). Add short notes on retained runs. Missing native values stay unavailable — never guessed.

🖼️ NEMESIS PORTRAITS
201 static creature portraits from local native art, matched by exact localized name. Unknown or ambiguous names keep the neutral icon.

🤝 CO-OP & ENCOUNTER OBSERVATIONS
Observed downs/returns and support attempts, boss sightings and shared boss-meter samples — without claiming successful revives or inventing kills.

🛠️ EDIT, HIDE, MANAGE
Per-page editing, reversible hides, targeted resets and Manage local data stay with you. Schema 1 is preserved; V2 data lives in a separate bounded extension. V1 ↔ V2 roundtrips keep ordinary history intact.

🎨 FIVE THEMES
Atelier, Grimoire and companions remain selectable, with transactional previews.

🔧 SESSION OVERLAY CONTROLS
`/azstats overlay off|on|bar|window` for live A/B diagnosis of screen stacking. Optional native “on top of screens” when the client provides it.

Updating
Close the game completely, replace the addon files with the player ZIP (not GitHub’s Source code ZIP), keep your existing AzerothStatsDB, then fully restart. No history reset needed.

Useful commands
/azstats — Open the addon
/azstats history — Browse runs
/azstats hud — Customize your stats bar
/azstats data — Manage local data
/azstats overlay — Session overlay diagnosis
/azstats diagnose — Diagnostics
/azstats help — Command help

Still a preview
Live multiplayer revive/encounter edge cases, some native packet orders and final visual polish still need player feedback. Summary-only counters can still say At run end until the official summary arrives. The native “Bougez pour commencer” overlay is outside this addon.

Found an issue? Include addon/client versions, class, steps and a screenshot or `/azstats diagnose` output. Please don’t post personal save files publicly.

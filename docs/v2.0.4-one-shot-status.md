## Delivered on branch

- Effects option wording now describes observed buffs/debuffs and missing native packets honestly.

- Insights locale source and generated output extended with explanatory copy for all shipped locales. French and English strings are reviewed; other locales currently use English fallback text and must be treated as untranslated pending native-language review.
- Highlights model now displays up to four recent build-journal changes instead of two.
- Read-only `/azstats storage` inventory reports active run count and manual/automatic backup snapshot/run-copy counts. It does not measure bytes.
- Tests guard the storage command against invoking backup creation/restoration/deletion paths.
- Co-op API audit documents current bounded, freshness-checked roster fields; no evidence of peer talents/equipment API was found.
- Abandoned-run policy documented; no destructive run suppression has been implemented.

## Explicitly not complete

- Round minimap icon remains unverified visually across Grimoire, Warcraft and other themes, including toggle/theme/reload sequences. CI theme fixtures are not a substitute for in-client screenshots.
- Square icon visual centering needs in-game confirmation.
- No byte-level SavedVariables measurement has been made on a real player profile. No compression or storage schema migration is implemented.
- The four-item Highlights change has CI coverage, but requires in-game confirmation of layout/overflow on all supported themes.
- Abandoned-run setting is not implemented. The policy requires careful aggregate-accounting and crash/reload design.
- Peer talents/equipment are not implemented because no supported API was established.
- Leaderboard remains out of scope pending separate identity, scoring, privacy and backend design.
- The new locale explanatory copy is only human-reviewed for English and French; other locales need translation review.

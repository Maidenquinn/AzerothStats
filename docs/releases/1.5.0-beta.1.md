Azeroth Stats 1.5 adds co-op comparisons, categorized favorites, death evidence and observed DPS milestones to the existing run-history and build-tracking addon.

## New since 1.4.0-beta.1

- **Co-op comparison:** view yourself and observed teammates in the same run, with damage, DPS and top spell where provided. Rankings and damage shares require one common group snapshot. Browse earlier runs and a companion's retained game history.
- **Favorites:** bookmark runs, combat views, spells, collection equipment, accessories and companions. Six separate categories with counters, class filters and clear empty/filled hearts. Favorite runs and new historical-combat source runs survive automatic pruning.
- **Nemesis:** observed death history, recent combat-log evidence and separate confirmed/probable/unknown attribution. A last attacker alone is labeled probable, not a proven killer. Hover reports to inspect retained evidence.
- **DPS records:** persistent global/per-class records for the highest observed run-average DPS sample after ten server seconds. Optional native record sound, at most once per run; the first class baseline seeds silently.
- **Interface and localization:** historical navigation, clearer scope, persistent category selection, heart controls and labels in all 14 supported languages.

## Download and installation

Download **AzerothStats-1.5.0-beta.1.zip** from the assets below. GitHub's Source code archives are not the ready-to-install package.

1. Exit the game normally. If updating, back up and retain your AzerothStats SavedVariables.
2. Extract the addon into the AddOns folder used by your running client. The final path must be `AddOns/AzerothStats/AzerothStats.toc`, without another release/source folder in between.
3. A common portable layout is `<game folder>/benilla-config/AddOns/AzerothStats/AzerothStats.toc`. If the addon does not appear in the list, check the actual client folder and nesting first.
4. Restart the game, type `/azstats` and verify **1.5.0-beta.1** in the header.

Existing run data and settings are retained; the SavedVariables schema remains 1. No game `.sav` import is included. Standalone Windows addon, interface 11200; no additional addon dependency or external account.

## New commands

- `/azstats coop` — open the latest/current co-op comparison.
- `/azstats favorites` — open categorized bookmarks.
- `/azstats favorite` — toggle the selected/current run as a favorite.
- `/azstats nemesis` — open death history and attacker evidence.
- `/azstats sound` — toggle record sounds.
- `/azstats sound test` — preview the native sound.

Existing `/azstats`, `history`, `diagnose`, `bar`, `minimap`, `lock`, `resetpos` and Settings controls remain available.

## Beta limitations

- Co-op data depends on native packets actually received. Peer healing/kills and shared achievements are not exposed. Old independent records remain partial; a retained party snapshot is not a guaranteed official final scoreboard.
- Nemesis confirmation requires an explicit native slain-by message, if emitted. Recent last-hit correlation remains probable; stale/missing evidence remains unknown. Old deaths are not reconstructed and per-enemy wins are not invented.
- Peak observed DPS is a run-average sample, not instantaneous burst DPS. Names are observed names, not stable account IDs.
- Favorites are capped at 300 bookmarks and 200 distinct protected runs. Old combat bookmarks without a stored run ID retain their original global scope.
- In-game feedback covered the interface, favorites and a probable Nemesis attribution. Every language, multiplayer configuration and native sound/death-message path has not been exhaustively validated.

# Azeroth Stats v2.0.3 — Discord announcement (English, draft)

**Azeroth Stats v2.0.3 — WoW Logs AS interoperability groundwork** 📊

We've been working on a safer way to share Azeroth Survivors run summaries with the WoW Logs AS ecosystem!

**What's new**
• **Manual AZST1 export:** use `/azstats interop export` to select a saved run, generate a compact summary, and copy it with Ctrl+A / Ctrl+C.
• **Native ID diagnostics:** `/azstats interop probe` helps inspect the game's run identifier without changing your saved data.
• **Clearer data semantics:** real zero values are preserved separately from metrics that were not available.
• **Privacy by design:** no automatic uploads, no network requests, and no raw combat logs, equipment, personal details, or backups in the export.

**Your existing data stays yours.** Run history, analysis, filters, favorites, and existing backups remain compatible with v2.0.2.

**Important:** This update lays the groundwork for WoW Logs AS integration. The AZST1 importer on the WoW Logs side is not available yet; the new feature is a manual export, not a live sync. The native run ID is intentionally not linked automatically until its lifecycle is confirmed.

Thanks for helping us test! 💙

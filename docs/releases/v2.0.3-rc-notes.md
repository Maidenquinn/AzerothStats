# Azeroth Stats v2.0.3 — Release candidate notes

**Status: release candidate / not published.** Prepared 2026-11-10 on PR #35.
Stable baseline: official v2.0.2 tag `5aa51561cbcf5783a7e3a0073df880e729ec7b82`.

## What's new
- Manual, opt-in **AZST1 v1** run summary export for future WoW Logs AS integration.
- In game: `/azstats interop export` opens the export window. Select a retained run, generate its `AZST1:` code, then copy the entire text (Ctrl+A, Ctrl+C).
- `/azstats interop probe` displays a **read-only diagnostic** of the native `AZS_ZONE.run` candidate. It does not attach or persist this candidate to run history.
- Exported summaries include run status/outcome, zone/class/difficulty, local run ID, timestamps and 13 allowlisted metrics. A measured zero is distinct from an unavailable metric.

## Compatibility and privacy
- Existing v2.0.2 SavedVariables, backups, run history, filters, favorites and analysis remain supported.
- Export is manual only: no network request, background upload, external service dependency, automatic collection beyond existing behavior, or transmission.
- Raw combat events, equipment links, tooltips, deaths, timelines, personal names and backup payloads are not included in AZST1.
- AZST1 is capped at 8,192 bytes per document; oversized documents are rejected rather than truncated.
- `nativeRunId` is intentionally `null` until its lifecycle and correlation scope can be safely established.

## Limitations
- WoW Logs AS does **not yet** import AZST1 automatically; Rakesh may request future contract changes.
- The exporter does not upload anything; users must manually copy the code.
- No global native run ID matching or automatic correlation is claimed.
- This release candidate is **not** an official published release.

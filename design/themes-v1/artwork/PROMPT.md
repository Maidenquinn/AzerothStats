# Grimoire production artwork — built-in ImageGen

Original generated bitmap asset, no Blizzard source artwork. Runtime uses only
small fixed TGA components; the source and generation prompt are development files.

Prompt:

Create one single square seamless-centered nine-slice texture for an elegant
premium fantasy journal GUI frame. Perfectly front-facing orthographic rectangle,
image bounds exactly match frame bounds. No text, letters, icons, numbers,
diagrams, decorative content in the center, screenshots, interfaces, shadows cast
onto an external surface, or perspective. Premium aged warm ivory parchment
center, fine subtle handmade paper grain and delicate organic mottling, softly
shaded margins. Outer frame: richly detailed narrow chestnut leather bookbinding,
small embossed antique bronze corner fittings, restrained oxblood leather inlays
and realistic handworked craftsmanship. Readable adventure log, refined rather
than dirty/burned. Border only outermost 6%; corner ornaments within 9%. Center 82%
empty light cream parchment with nearly uniform reading brightness. Opposing
straight edges use constant cross-sections suitable for nine-slice scaling. No
middle-edge ornaments, central crest, drop shadow or surrounding margin.
Warcraft-like fantasy RPG craftsmanship, original artwork. Intended to be
resampled to 256×256 RGBA and sliced into bounded native components.

# Crédits et ressources

Azeroth Stats : Kevin / Codex. Addon destiné à Azeroth Survivors.

Les chemins Interface référencent les bordures/icônes natives du client. Les vignettes de zones incluses dans ce paquet sont décrites séparément ci-dessous.

Les polices dérivées Noto Sans, Noto Serif et Noto CJK sont incluses avec leurs mentions légales et licences SIL Open Font License dans `media/OFL-NotoSans.txt` et `media/OFL-NotoCJK.txt`. Les variantes CJK ont été réduites aux caractères utilisés et renommées.

Le catalogue de correspondances et de sources de butin est dérivé du catalogue local Azerloot, lui-même établi depuis les données du jeu. Azerloot n’est pas chargé ni requis. Les bonus arrondis de ce catalogue ne servent pas de bonus exacts : les descriptions natives du client sont prioritaires.

The empty and filled favorite-heart glyphs are original geometric artwork for this addon, encoded as 32-bit RGBA TGA textures. No third-party image or game artwork was copied to create them.

Chroniques compass, glyph atlas, grain and backdrop-edge textures are original geometric artwork generated by tools/build_theme_assets.py. No game artwork is used as an input. The concept board is an AI-generated design proposal, not a client screenshot. CJK derivative glyph coverage is extended using hash-verified original Noto inputs; OFL notices and derivative naming are retained.

The sculpted frame proposal, painted sixteen-glyph atlas, retired decorative landscape proposal and material plate atlas are original AI-generated artwork prepared with Codex ImageGen, inspired by the approved concept. Source PNGs are committed under design/chroniques-v1; tools/encode_painted_assets.py slices/resamples the glyph and material sources into small native components for the native client. They are not Blizzard assets or captured gameplay. The full-frame source PNG is retired from the runtime package. The bold heading face is an OFL Noto Serif Bold derivative renamed by tools/build_title_font.py; data/title-font-source.json records its pinned official input and hash. The addon loads fixed local TGA files, with no generation/download at runtime.

Recent-run zone photos: twelve JPEG images supplied by the maintainer in images zones.zip. Original bytes are retained under design/run-images; archive/source hashes and filename-to-zone associations are recorded in data/run-image-sources.json. These images depict Warcraft locations; original creators/licenses were not supplied. No original authorship or official affiliation is claimed. tools/build_run_images.py resamples/encodes the full sources; native UV framing provides thumbnail crops. The generated landscape proposal is retired from the runtime.

Five-theme development preview: GrimoirePlate1..4.tga are original deterministic parchment artwork generated by tools/build_grimoire_assets.py. Warcraft references fixed stone borders, red button textures and icons already installed in the client; no Blizzard resource is copied into the player ZIP. Native UV coordinates follow the client's UIPanelTemplates.xml. Atelier/Essentiel use original geometric glyphs and solid native texture colors. Theme miniatures are drawn by the addon itself, not generated screenshots. See docs/VISUAL-THEMES.md in the source repository for paths, boundaries and test instructions.
